# Third-party assets

Everything in this repository is original work generated by the scripts under `blender/`, with one exception: the realistic player. This file records every outside asset that goes into it, where it comes from, and its license. Keep it in step with the asset list at the top of `blender/cast/generate_realistic_player.py`, and add a row in the same change whenever an outside asset is added anywhere.

Only take assets whose license permits use and redistribution in a private repository that may ship. CC0 is preferred.

## Realistic player

`public/assets/cast/player-realistic.glb` is built by `blender/cast/generate_realistic_player.py` with [MPFB](https://static.makehumancommunity.org/mpfb.html) (MakeHuman Plugin For Blender) 2.0.18.

MPFB is only a build tool here. Its source code is GPL-3.0-or-later, and none of it is in this repository or in the game. The data it builds characters from is CC0 1.0, so the generated model carries no license obligation, attribution included.

| Asset | What the model takes from it | Comes with | License |
| --- | --- | --- | --- |
| MakeHuman base mesh (`base.obj`), including its skirt and tights helper geometry | Head, neck, ears, and hands. The skirt and leggings are cut from the helpers; the beanie and the head scarf's wrap are layers fitted over the head. | MPFB 2.0.18 | CC0 1.0 |
| MakeHuman morph targets | A young child's proportions and round face, a slight smile, relaxed eyes | MPFB 2.0.18 | CC0 1.0 |
| `game_engine` rig and skin weights | The skeleton | MPFB 2.0.18 | CC0 1.0 |
| Skin `young_caucasian_female` | Skin detail, turned into a neutral map that the chosen tone multiplies. Every region the clothes cover is blanked. | MakeHuman system assets | CC0 1.0 |
| Eyes `low-poly` with the `brown` iris texture | Eyes | MakeHuman system assets | CC0 1.0 |
| Eyebrows `eyebrow001`, eyelashes `eyelashes01` | Shape only; both are recolored | MakeHuman system assets | CC0 1.0 |
| Hair `short02` and `long01` | Boy and Girl hair, each whole: the part below the beanie's brim shows under a hat, the rest on a bare head. Strand detail only, in one shared color. | MakeHuman system assets | CC0 1.0 |
| Clothes `male_casualsuit02` | Top and trousers. Only fold shading and the denim weave are kept; the print on the shirt is not used. | MakeHuman system assets | CC0 1.0 |
| Clothes `shoes06` | Sneaker and sock shapes. Its texture is not used. | MakeHuman system assets | CC0 1.0 |

The idle and walk animations are written in the generator; no motion capture is used.

- License statements: <https://github.com/makehumancommunity/mpfb2/blob/master/LICENSE.md> and <https://static.makehumancommunity.org/about/license.html>. The base mesh, the weights, and every pack file used also say so themselves ("explicitly released as CC0 in september 2020"), and the pack's manifest lists all 94 of its entries as CC0.

None of the source files are committed. Only the generated model and its preview render are.

## Everything else

The cartoon player, both friends, Camo, the living room, the ball, and the block are generated from Blender primitives and procedural materials. They use no outside textures, fonts, or models.
